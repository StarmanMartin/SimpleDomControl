# sdc_user: controllers and data models

Generated by `manage.py sdc_teach --per-app` on 2026-10-30. Open a controller by navigating to `/~<tag>` (nested views: `/~parent~child`); arguments follow after `~&` as `key=value` pairs joined by `&` and reach the view as `data-*` attributes.

## Controllers

### `<register>`

Registration form that creates a new `SdcUser` account; open it from the "Register" link of `<sdc-login>` or `<sdc-user-nav-btn>`.

- Arguments: `model` must be `SdcUser`; `next` is where to go after creating (the links pass `..`, i.e. back).
- Fields: `username`, `first_name`, `last_name`, `email`, the password and its confirmation (must match and pass the password rules).
- "Create" creates the account; anyone may register, no login is needed. The new user is not logged in automatically.
- If an `email` was given, a confirmation e-mail with a link to `<sdc-confirm-email>` (valid 3 days) is sent to it.
- If the project requires confirmed e-mail addresses, the new user can only log in after following that link.

_server view `sdc_user.sdc_views.Register`, Django URL `/sdc_view/sdc_user/register`_

### `<sdc-change-password>`

Form for the logged-in user to change their own password (the `password_form` of `SdcUser`).

- No arguments; it always edits the current user. Requires login, otherwise it redirects to the login view.
- Enter the current password, then the new password twice (must match and pass the password rules).
- "Change password" saves the new password immediately. Other sessions of this user are logged out; the current session stays logged in.

_server view `sdc_user.sdc_views.SdcChangePassword`, Django URL `/sdc_view/sdc_user/sdc_change_password`_

### `<sdc-confirm-email>`

Confirms the e-mail address of an `SdcUser`; this is the target of the link in the confirmation e-mail.

- Arguments: `token` (required) is the token from the e-mail link (`/~sdc-confirm-email~&1.token=...`).
- Opening the view with a valid token immediately marks the address as confirmed (`email_confirmed`) and shows a success message; there is nothing to click. No login is needed.
- Each token works once and is valid for 3 days. An expired token automatically sends a new confirmation e-mail; an invalid or already used token shows "No valid token.".

_server view `sdc_user.sdc_views.SdcConfirmEmail`, Django URL `/sdc_view/sdc_user/sdc_confirm_email/<str:token>`, required URL params `token`_

### `<sdc-login>`

Login form (username and password) that starts a session for an `SdcUser`; the view other views redirect to when login is required.

- Arguments: `next` (optional) is the URL to go to after login; without it the project's start page (`LOGIN_SUCCESS`) is used.
- "Login" checks the credentials. On success the user is logged in and the whole page reloads at the `next` target; on failure the errors are shown in the form.
- If the project requires confirmed e-mail addresses and the user has not confirmed theirs, login is refused and a new confirmation e-mail is sent.
- Links lead to `<sdc-password-forgotten>` and to `<register>`.

_server view `sdc_user.sdc_views.SdcLogin`, Django URL `/sdc_view/sdc_user/sdc_login`_

### `<sdc-logout>`

Logout button; usually embedded in `<sdc-user-nav-btn>` when a user is logged in.

- "Logout" ends the session of the current user immediately (no confirm dialog) and redirects to the login view; the WebSocket connections are reopened as anonymous user.

_server view `sdc_user.sdc_views.SdcLogout`, Django URL `/sdc_view/sdc_user/sdc_logout`_

### `<sdc-password-forgotten>`

Requests a password-reset e-mail for a user who forgot their password; reached from the "Password forgotten" link of `<sdc-login>`.

- No arguments and no login needed. Enter the username or the e-mail address of the account.
- "Send E-mail" sends an e-mail with a link to `<sdc-reset-password>` to the account's address; the link is valid for 3 days and can be used once.
- Shows "User not found" if no account (or more than one) matches, and an error if the e-mail could not be sent.

_server view `sdc_user.sdc_views.SdcPasswordForgotten`, Django URL `/sdc_view/sdc_user/sdc_password_forgotten`_

### `<sdc-reset-password>`

Sets a new password with a reset token; this is the target of the link in the password-reset e-mail sent by `<sdc-password-forgotten>`.

- Arguments: `token` (required) is the token from the e-mail link (`/~sdc-reset-password~&1.token=...`); it is kept in a hidden form field.
- Enter the new password twice (at least 8 characters, must match and pass the password rules). No login is needed.
- "Reset Password" sets the new password and shows "Password has been reset."; the user is not logged in and must then use `<sdc-login>`.
- Each token works once and is valid for 3 days. An expired token automatically sends a new reset e-mail; an invalid or used token shows an error.

_server view `sdc_user.sdc_views.SdcResetPassword`, Django URL `/sdc_view/sdc_user/sdc_reset_password`_

### `<sdc-user>`

Invisible global helper that loads the `SdcUser` record of the logged-in user (nothing for anonymous visitors) and provides it to other controllers on request; it shows no content and has no actions.

_server view `sdc_user.sdc_views.SdcUser`, Django URL `/sdc_view/sdc_user/sdc_user`_

### `<sdc-user-nav-btn>`

User area for the navigation bar: shows "Login" and "Register" links when nobody is logged in, and an "Edit <username>" link (opens the user's own `SdcUser` in `<sdc-model-form>`) plus `<sdc-logout>` when a user is logged in. It refreshes itself after login and logout.

_server view `sdc_user.sdc_views.SdcUserNavBtn`, Django URL `/sdc_view/sdc_user/sdc_user_nav_btn`_

## Data models

SDC models are loaded and saved over the model WebSocket (`this.querySet("Name", {filter})` in a controller).

### `SdcUser`

A user account of the site (the project's Django user model); one record per person who can log in.

- `username` (unique, used to log in), `first_name`, `last_name`, `email`; `is_staff`, `is_superuser`,
  `is_active`, `groups`, `date_joined`, `last_login` as in Django's standard user.
- `email_confirmed`: `true` once the user followed the link in the confirmation e-mail (`<sdc-confirm-email>`).
- The password is never sent to the client; it is changed with the `password_form` (`<sdc-change-password>`)
  or reset by e-mail (`<sdc-password-forgotten>`).
- Anyone may create an account (registration in `<register>`). By default a logged-in user can read and
  edit only their own record (`username`, names, `email`); superusers can see and edit all users, and only
  superusers may delete users.
- Saving a new or changed `email` resets `email_confirmed` to `false` and sends a confirmation e-mail to
  that address (link valid for 3 days).
- Edited in `<sdc-model-form>` via the "Edit <username>" link of `<sdc-user-nav-btn>`; `<sdc-user>` loads
  the current user's record.

Fields: `id` (BigAutoField), `last_login` (DateTimeField), `is_superuser` (BooleanField), `username` (CharField), `first_name` (CharField), `last_name` (CharField), `email` (CharField), `is_staff` (BooleanField), `is_active` (BooleanField), `date_joined` (DateTimeField), `email_confirmed` (BooleanField), `groups` → `Group`, `user_permissions` → `Permission`
